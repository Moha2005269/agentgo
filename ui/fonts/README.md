# Bundled UI fonts

These Latin webfont subsets are bundled so the trusted landing surface does
not depend on a font CDN during first paint:

- IBM Plex Mono 400/500/600
- Instrument Serif normal/italic
- Manrope variable Latin

Each family is distributed under the SIL Open Font License 1.1. The matching
license text is kept beside the font files. The binary assets are the official
Google Fonts webfont files used by the approved UI typography.
