    No API. That's the point.

    UPDATED MAY 2025 · 4 MIN READ

    Most "agent browsers" expose an API and serve a simulated web. AgentGo inverts that: the agent operates the browser itself — the same window, the same buttons, the same pages you see.

    Any app that can issue input gets first-class control. Launch AgentGo from your terminal and your agent attaches instantly:

    # launch from any agent app $ agentgo launch --grant codex ▸ window ready · agent attached ▸ control level: same as operator ▸ approvals: purchases gated · kill switch armed
    WHY THIS MATTERS Your agent sees the web exactly as you do — no stale API mirror, no missing features. If you can click it, your agent can click it.

    Every agent app speaks the same primitives:

    ACTclick · type · scrollReal input events on the real pageparity
