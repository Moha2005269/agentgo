# Changelog

## 0.1.1 (2026-10-17)

- **AgentGo Setup**: a graphical installer (`AgentGo-Setup.exe`, and an offline `AgentGo-Setup-full.exe`). A floating card on a transparent window that unfolds from the AgentGo mark; license, folder, shortcuts, PATH, agent registration (Claude Code, Codex, Droid), preferences, an install that checks every file against its SHA-256, import from your old browser, and an uninstaller in Windows Settings. Per user, no administrator rights. `--silent` installs and uninstalls without a window for scripted deployments.
- **Fingerprint protection, hardened**: the hooks are proxies of the native functions (they read as `[native code]`, with the right name and length); blank and `srcdoc` iframes and `window.open` popups are covered; `OffscreenCanvas` and `AudioBuffer.copyFromChannel` reads are covered; noise is keyed to the pixel position; spoofed CPU and memory numbers are dropped (workers reported the real ones, and the mismatch itself identified the browser).
- **Fingerprint modes fixed**: the first page of a new tab was unprotected, and switching between the person's mode and the agent's mode could be lost when it raced a running install. Both fixed and tested, including that the agent keeps its fingerprint across restarts.
- **Dangerous-site protection**: every page is checked before it loads against 35,000+ known malware and phishing hosts (URLhaus, uBlock Badware, Phishing URL Blocklist from OpenPhish, PhishTank and IPThreat) and by look-alike detection that needs no list: letters from other alphabets (`pаypal.com`), a brand's domain used as a subdomain (`paypal.com.verify.top`) and a brand next to a lure word (`paypal-login-secure.com`). Checked on this computer; no address is sent anywhere. Zero look-alike false positives across the 100,000 most visited sites. Blocked pages show a warning; the person may open one anyway, an agent never can (not even after disconnecting: a click that came with agent input is refused).
- **More privacy by default**: third-party cookies blocked; tracking parameters (`fbclid`, `gclid`, `msclkid`, `utm_*` and 40 more) removed from addresses before the request; the Global Privacy Control signal sent (`Sec-GPC: 1`, `navigator.globalPrivacyControl`); notification requests refused. Each has a switch in Settings, Privacy.
- **WebRTC**: pages only ever learn the default route's public address (`default_public_interface_only`); private interfaces and VPN adapters stay hidden.
- `browser.launch` reports the browser's own process id (it reported a launcher that had already exited).
- **Import**: Chrome passwords saved to the Google account (`Login Data For Account`) are imported; profile counts no longer read 0 while the other browser is open; the history limit is 20,000 and the sign-in vault holds 5,000 sign-ins. Passwords Chrome seals with app-bound encryption come over through Chrome's own export: the import offers "Open Chrome export" and "Choose CSV file". New `agentgo import` command (scan, import, `--csv`, `--open-export`).
- **MCP**: `agentgo setup claude` registers for the user (every project), not only the current folder; `agentgo setup droid` no longer stores the path without its backslashes (Droid could not start AgentGo).
- **Automatic updates**: AgentGo checks the latest GitHub release shortly after it starts and every six hours. A new version must carry AgentGo's Ed25519 release signature and match its SHA-256; it downloads in the background and goes in when you close AgentGo (a "Restart to update" button does it now). With "Update automatically" off (Settings, About, or in Setup), an "Update to x.y.z" button appears in the toolbar instead. Installed copies update through AgentGo Setup with the same film as installing ("Updating", then "Updated to x.y.z"), shown once AgentGo has closed. Updates replace only the program folder: profiles, saved sign-ins, accounts, history and settings live in `%LOCALAPPDATA%\AgentGo` and are never touched, and Setup refuses any folder that holds them. The uninstaller and the Windows version entry survive updates; `browser.update_rollback` goes back. (The on-exit swap used to give up after two minutes; it now waits for AgentGo to close.)
- **Developer tools**: a close button in their corner (F12 inside them closes too); right-click Inspect while they are open inspects the new element instead of closing them; closing them, or closing a tab with them open, no longer blanks the toolbar or the window (D88).
- **Extensions**: the Chrome Web Store's own "Add to Chrome" button now installs into AgentGo (it used to start the engine's internal install, which never finished and never reached AgentGo's pages; only the person's click on that extension's own page counts). Extension content scripts get `chrome.runtime`, `chrome.i18n` and `chrome.storage` (saved across page loads); extensions that need a background page are labelled as limited. Packages signed with older 1024-bit keys (Google Translate) install (D89).
- **Lighter and less conspicuous** (measured with techinz/browsers-benchmark, `docs/benchmarks/browsers-benchmark.md`): the back/forward cache is off, so memory stays flat instead of growing by a renderer per site (2.2 GB to 1.4 GB over ten sites); pages no longer see AgentGo's markers (named globals, a permanent agent layer, proxy frames in error stacks). 8 of 10 bot-protected sites came through, against 7 for stock Chromium; reCAPTCHA v3 score 0.9.
- The toolbar names agents the way people know them ("Claude Code connected").
- The browser window (and AgentGo Setup) open in the middle of the screen, sized to fit it, instead of the top-left corner.
- CI: the capability-manifest hash ignores line endings and the lockstep test checks each capability's own integration test file.
- AgentGo Setup: `--uninstall --silent` removes the whole folder and its temporary copy (it exited 1 and left both behind, D91), and installs flat into its folder so the shortcuts, PATH and agent registrations find AgentGo (D93). The package no longer carries duplicate locales or SDK build leftovers (220 MB to 198 MB).
- New live test `security_live_e2e` (badssl certificate errors, WebRTC, adblock-tester.com, fingerprint modes on real sites, CreepJS, EFF Cover Your Tracks).

## 0.1.0 (2026-10-16)

First public build.

- Browser: tabs, history, bookmarks, favorites bar, downloads, find, zoom, print and print to PDF, session restore, Settings with search, extensions from the Chrome Web Store.
- Agent control: MCP server, CLI and JSON-lines protocol; compact page outlines; approvals for payments; CAPTCHA and sign-in hand-off; audit log.
- Privacy: Brave adblock engine with 18 lists, cosmetic filtering and YouTube ad removal; fingerprint noise; site permissions that ask (Keep blocked, Allow this time, Always allow).
- New: command palette (Ctrl+K), first-run welcome and import (Chrome, Edge, Brave, Firefox; bookmarks, history, passwords incl. Firefox NSS, exact open tabs), dark mode for websites, selection and page translation with a "Translate into" setting, report a problem, prompt-injection scanner, animated New Tab demo.
- Removed: the VPN (the Settings card says "coming soon").
- Faster debug builds (dependencies are optimised) and a retrying translation request.
- Known limits: not Authenticode-signed; Chrome v20 (app-bound) passwords can't be imported directly (use CSV).
