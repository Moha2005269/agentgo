## 2. Architecture as it is now (`crates/agentgo-cef/src/runtime/`)

| File | Role |
|---|---|
| `exec.rs` | Tiny single-thread async executor on the CEF UI thread; `post()` for other threads |
| `dispatch.rs` | **The one command dispatcher** for stdio, pipe and the shell bridge: gates, leases, idempotency, audit, workflows (`batch`, `collect`, `navigate.url`) |
| `sessions.rs` | Sessions, tab leases, pause/stop, approvals, handoff, activity |
| `cdp.rs` | In-process DevTools client (no debugging port); isolated world `agentgo` |
| `agent.js` | Page agent in the isolated world: compact outline with numeric refs, targets, text/links/tables/forms, settle, challenge and payment signals |
| `page.rs` | observe/act/wait/screenshot/pdf/cookies/dialog handlers; trusted input via `Input.*` |
| `pipe.rs` | `\\.\pipe\agentgo-<instance>`: current-user ACL, token in `instances\<id>\token`, session per connection |
| `scheme.rs` | Bundled assets + async bridge (answers on the UI thread through `dispatch`) |
| `state.rs` | Tabs, window, settings, history, downloads, profile root, legacy sync handlers (`handle_protocol_request`) |
| `app.rs` | CEF app/client/handlers, window composition, tick task |
| `notify.rs` | Taskbar flash + Windows notification |

Other: `agentgo-mcp` now holds `client.rs` (pipe attach / child launch) and
`server.rs` (MCP stdio server, 9 tools, < 4 KB of definitions);
`agentgo-shell-bridge/src/methods.rs` is the registry (127 commands, 125
implemented, each naming its integration test) and feeds `browser.capabilities`.
UI: `ui/chrome.{html,js}`, `ui/tools.{html,js}`, `ui/index.html` + `ui/newtab.js`
(generated by `scripts/dev/build-newtab.js` from the prototype, which is
`git show HEAD:ui/index.html`).
